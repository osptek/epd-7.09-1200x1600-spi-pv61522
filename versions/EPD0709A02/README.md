## 产品简介

OSPTEK **7.09 寸 1200×1600 EPD** 是一款 **SPI** 接口六色电子纸显示模组（黑 / 白 / 红 / 黄 / 蓝 / 绿）。驱动 IC 型号待确认，仓库名暂用 **TBD**；确认后将更名并同步更新本页。

规格标识（仓库名）：`epd-7.09-1200x1600-spi-tbd`

当前模组版本：**EPD0709A02**。电气与外形细节以 [`docs/EPD0709A02.pdf`](./docs/EPD0709A02.pdf) 为准。
